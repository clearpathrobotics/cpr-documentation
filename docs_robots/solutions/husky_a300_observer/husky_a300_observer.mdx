## Introduction
  ### About
  The Husky Observer uses a Husky A300 AMP as its base.
  The AMP includes the Husky A300 base robot, sensors, autonomy navigation software, and a web user interface for commanding the robot.
  Husky Observer then adds Autonomous Wireless Charging, and a Pan Tilt Zoom Camera.
  This manual will explain how to use your Husky Observer, how to add new hardware and software, and how to maintain the robot.

## Custom Integrations
  <ComponentRiskAssessmentForIntegrations />
  :::note Interfaces

  The Husky Observer uses a Husky A300 AMP as its base.
  * Husky's electrical interfaces and computer still exist in the base robot.
    Refer to the [Husky A300 Integration page](/docs_robots/outdoor_robots/husky/a300/integration_husky) page if you want to make use of these interfaces, such as the Husky's GPIO.
  * Husky AMP's integration cabinet is available, so you can add custom modules within the IP54 water resistant enclosure.
    Refer to the [Husky AMP Integration page](/docs_robots/solutions/husky_a300_amp) page for details.

  :::
