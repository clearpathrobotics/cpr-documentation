Once the simulator has been [installed](install.mdx), you can launch the simulation.

## Launching the simulator

Launch files for the simulation can be found in the `clearpath_gz` package, which is installed as part of the `clearpath_simulator`
metapackage. The default launch file for launching the simulation environment and spawning your robot is
[simulation.launch.py](https://github.com/clearpathrobotics/clearpath_simulator/blob/jazzy/clearpath_gz/launch/simulation.launch.py).

It can be called like this:

```
ros2 launch clearpath_gz simulation.launch.py
```

The launch file will run all of the necessary [generators](../../config/generators.mdx) to generate launch and parameter
files for the simulation before launching Gazebo and spawning the robot. These will be placed under the setup path
(defaults to `$HOME/clearpath/`).

:::note

The simulator does not generate a `setup.bash` file, so it does not apply the `domain_id` or
`middleware` settings from the [`system.ros2`](../../config/yaml/system.mdx#ros-2-environment) section of `robot.yaml`.
The ROS domain and RMW implementation come from each terminal's environment instead. Every
terminal used with the simulation, including terminals running Nav2, SLAM, RViz, or `ros2`
commands, must use the same `ROS_DOMAIN_ID` and `RMW_IMPLEMENTATION`.

:::

To use the simulator with Zenoh, see [Using Zenoh with the Simulator](zenoh.mdx).
For an isolated simulator using Cyclone DDS, see
[Using Cyclone DDS with the Simulator](cyclone.mdx).

### Launch arguments

If you are using a different setup path, use the `setup_path` launch argument to change it:

```
ros2 launch clearpath_gz simulation.launch.py setup_path:=$HOME/setup/path/
```

The Gazebo world (defaults to `warehouse`) can be changed using the `world` launch argument:

```
ros2 launch clearpath_gz simulation.launch.py world:=my_world
```

:::note

The launch file will look for the world `.sdf` file inside the
[worlds](https://github.com/clearpathrobotics/clearpath_simulator/tree/main/clearpath_gz/worlds)folder of the `clearpath_gz` package.

:::

The position and orientation of where the robot is spawned can be changed:

```
ros2 launch clearpath_gz simulation.launch.py x:=1.5 y:=2.7 yaw:=1.5707
```

To launch Rviz along with the simulation, use the `rviz` launch argument:

```
ros2 launch clearpath_gz simulation.launch.py rviz:=true
```

To run Gazebo without the GUI (for example on a server or in CI), use the `headless` launch argument.
This starts the Gazebo server only, with headless rendering so simulated sensors still work without a display:

```
ros2 launch clearpath_gz simulation.launch.py headless:=true
```

## Driving the robot

The simulated robot can be driven in the same ways as the physical robot. Take a look at the [Teleop](../driving.mdx)
guide for details. In addition, the Gazebo Teleop GUI plugin can be used. The plugin will be visible by default when
Gazebo is launched. If your robot has a namespace, change the topic to `<namespace>/cmd_vel`. Set the maximum forward
and yaw velocities, then select the method of driving.
